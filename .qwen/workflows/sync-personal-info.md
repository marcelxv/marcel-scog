# Sync Personal Information

Update name, title, location, and email across components from resume.md.

## Steps

1. Run `node scripts/update-personal-info.js`
2. Check `src/components/hero/hero-section.tsx` ID card data
3. Check `src/app/layout.tsx` metadata
4. Run `npm run type-check`

## Usage

```
npm run workflow:sync-personal
```

Or ask the agent: "Sync my personal info from resume"
