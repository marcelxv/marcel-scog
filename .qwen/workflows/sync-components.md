# Sync Resume to React Components

Update experience timeline, skills section, and hero content from resume.md.

## Steps

1. Run `node scripts/update-experience-component.js`
2. Run `node scripts/update-skills-component.js`
3. Run `node scripts/update-hero-content.js`
4. Verify changes in components
5. Run `npm run type-check`

## Usage

```
npm run workflow:sync-components
```

Or ask the agent: "Sync resume data to React components"
